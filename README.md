# Retinal Age Atlas

Separate vessel, optic-disc and macula ages from a single fundus photograph, plus a two-eye comparison, tested as screening signals that separate retinopathy groups in ODIR-5K. Research code; not a diagnostic tool.

Status: pre-registration pending. No results yet.

## Setup

```
uv sync
uv run ruff check
uv run ruff format --check
uv run pytest
```
